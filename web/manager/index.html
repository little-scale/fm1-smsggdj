About ROM compatibility and recovery

A ROM with different code needs the JSON profile from the same build, including its SHA-256 and editor RAM symbols. The built-in ROM remains in the firmware. If an upload is interrupted, it is used on the next boot. Your SRAM journal occupies a separate flash area.

Download the bundled v0.48 profile. Create profiles for new builds with the project’s tools/make_profile.py.

Files stay in this browser until you download them or explicitly send them to a device.
