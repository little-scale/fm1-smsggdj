Controls · getting started

Create a chain with GLO on SONG, then hold REC and press Right to enter CHAIN. Create a phrase with GLO, then REC + Right to enter PHRASE. Hold REC and tap GLO to start or stop playback.

Keys are numbered from zero at the left end of the keyboard. Save a song through FILES before switching off; wait for CARTRIDGE SAVED. After restarting or importing SRAM, use FILES → LOAD.

Help & recovery

FM1 not found: check that the USB cable carries data, allow MIDI/SysEx permission, and close another updater that may be using the port. Advanced connection lets you select ports manually.


Update interrupted: keep the same firmware file, reconnect, choose it again, and install to finish the update. The page recognises the update loader and verifies the identity after restart.


M-VAVE Open firmware: restore the verified stock V15 file first, then install SMSGGDJ. Download the official FM-1.fwsc, choose it under Firmware, and install. The exact stock-file checksum is checked.


Return to stock: choose that same verified V15 file under Firmware. Export songs or patches first; returning to stock can erase saved data.


FM1 will not start or answer: follow the platform’s recovery instructions.
